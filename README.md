
Daily Korean Vocab (데일리 한국어)

 1. 프로젝트 소개 / 项目简介
 이 프로젝트는 한국어 학습자를 위한 '오늘의 단어' 학습 포털입니다. 파편화된 시간을 활용하여 매일 핵심 어휘를 기억할 수 있도록 돕습니다.
 这是一个为韩语学习者设计的“每日一词”学习门户，旨在利用碎片化时间帮助学习者每日记忆核心词汇。

 2. 주요 기능 / 主要功能
 Daily Focus (오늘의 핵심 단어)：精选每日核心词汇，包含韩文、罗马音及释义。
 Flip Card Interaction (카드 뒤집기 인터랙션)：点击卡片揭晓含义，增强学习互动感。
 Progress Tracking (학습 진행 상황 추적)：展示连胜天数与进度，激励持续学习。

3. 사용한 AI 도구 / 使用的 AI 工具
AI 도구: Cursor 및 Gemini를 활용하여 코드 프레임워크와 로직을 구현했습니다.
 使用 Cursor 和 Gemini 构建核心代码框架与逻辑。

 4. 기술 스택 / 技术栈
Framework: Next.js
Styling: Tailwind CSS
Deployment: Vercel (Cloud Infrastructure)

 5. 개발 과정에서의 고민과 해결 / 开发过程中的优化与挑战
문제: 초기 코드의 모바일 최적화 및 상태 관리 로직에 문제가 있었습니다.
최적화: 카드 뒤집기 로직을 직접 수정하고 Tailwind 반응형 설정을 조정하여 최적의 UI를 구현했습니다.

 6. 실행 방법 / 运行方法
온라인 서비스 (Live Demo)
https://daily-korean-vocab.vercel.app/

로컬 실행 (Local Setup)
1. git clone https://github.com/chenranyi152-stack/daily-korean-vocab
2. npm install
